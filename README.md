# TalentProof AI

An AI-resistant, skill-based hiring platform that helps companies hire developers using identity-verified assessments and evidence-backed skill profiles.

## Problem
Recruiters face AI-generated resumes, inflated experience claims, and unreliable online assessments. It is difficult to identify candidates with genuinely proven technical ability.

## Solution
TalentProof AI lets candidates demonstrate their skills through standardized DSA and practical coding assessments. Recruiters discover candidates using verified identity status, assessment scores, skills, and performance evidence—not resumes alone.

## MVP Features
- Recruiter talent discovery and skill-based filtering
- Verified candidate profiles
- Assessment scorecards
- Practical coding assessment workflow
- Candidate shortlisting
- Integrity-check and identity-verification UI

## Tech Stack
HTML, CSS, JavaScript  
Planned production stack: React, TypeScript, Node.js, PostgreSQL, Drizzle ORM, AWS, OTP and face-verification APIs.

## Demo Notice
The current MVP demonstrates the intended hiring workflow. Identity and proctoring checks are simulated and would require secure, consent-based provider integrations in production.
